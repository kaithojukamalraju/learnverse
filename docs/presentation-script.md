## PRE-RECORDING CHECKLIST ✅

Before you hit record, confirm everything below is working:

```
□ pnpm dev running → http://localhost:6050 loads in < 2s
□ Logged into account (so no login screen delay)
□ Nova AI chat responds (GEMINI_API_KEY set in .env)
□ Cell Explorer 3D loads smoothly (open Simulate tab first)
□ Quiz has questions (not blank)
□ No browser notifications / pop-ups
□ Chrome: bookmarks bar hidden (Ctrl+Shift+B to toggle off)
□ Zoom: 100% (Ctrl+0)
□ OS dark mode ON so browser chrome looks clean
□ Recording software ready (OBS / Loom / Camtasia)
□ Mouse cursor: use a large/colored cursor for visibility
```

| Tip | Detail |

| **Audio** | Use external mic if available, or quiet room |

| **Pacing** | Slow mouse, 2s pauses between clicks |
